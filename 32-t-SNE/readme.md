Команда 32:

## Содержание

- `t-SNE.pdf` — презентация по t-SNE, 20 слайдов.
- `src/demo.py` — пример на Python: визуализация digits, сравнение с PCA, влияние perplexity и инициализации, пошаговый численный пример.
- `src/requirements.txt` — зависимости.

## Запуск

Python 3.12. Из каталога `32-t-SNE`:

```bash
python -m pip install -r src/requirements.txt
python src/demo.py
```

Датасет digits входит в scikit-learn. Скрипт использует все 1797 объектов и 64 признака, фиксированные seed и один поток. Метки цифр не участвуют в построении проекций.

Скрипт сохраняет координаты проекций, метрики, параметры среды и промежуточные вычисления численного примера в `results/experiment.json`, сводные метрики — в `results/metrics.json`. Каталог `results/` создаётся при запуске.

В численном примере явно заданы четыре синтетических объекта A=0, B=1, C=4, D=5 и sigma=1. Скрипт проверяет нормировку вероятностей, градиент через конечные разности и уменьшение KL после шага.
